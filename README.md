# 구매 행동 분석 기반 고객 세분화 및 CRM 전략 제안
RFM 기반 고객 세분화와 제품 카테고리 구매 패턴 분석을 통해
고객 단계에 맞는 CRM 액션과 캠페인 방향을 제안한 프로젝트입니다.

## 분석 목적
구매 행동 데이터를 기반으로 고객을 RFM으로 세분화하고,
고객군별 쿠폰 상태와 제품 카테고리 구매 침투율 차이를 분석하여
고객 단계에 맞는 CRM 액션과 캠페인 방향을 도출합니다.

## 주요 분석 흐름
1. 고객·구매·쿠폰 데이터 결합 및 RFM 지표 생성
2. RFM Score 기반 고객 4개 Segment 세분화
3. 고객군별 쿠폰 상태 및 제품 카테고리 구매 침투율 비교
4. Segment별 CRM 액션 및 캠페인 방향·성과지표 설계

## 사용 기술
- Python
- pandas
- numpy
- matplotlib
- seaborn

## 주요 분석 결과
- RFM 기반으로 고객을 이탈 위험 / 일반 / 우수 / VIP 고객으로 구분
- 고객군별 쿠폰 상태 비율에는 큰 차이가 나타나지 않음
- 주요 제품 카테고리는 고객군별로 유사했으나 구매 침투율에는 차이가 나타남
- 고객 단계별 재방문, 반복 구매, VIP 전환을 위한 CRM 액션 제안
